# 06 · 治理与评审清单

> 怎么改、谁来批、什么算完成。
> 目标不是“写得好看”，而是**半年后换一个人/一个 AI 接手，界面仍然一致**。

---

## 1. 唯一真源

| 内容 | 真源 | 说明 |
|---|---|---|
| 数值 | `design-tokens.css` / `design-tokens.json` | 颜色/字号/间距/圆角/时长 |
| 视觉 | `prototypes/home-paper-v2.html` + `screenshots/home-paper-v2.png` | 当前基准 |
| 规则 | `README` + `01`–`06` | 本文与各分册 |
| 变更 | `CHANGELOG.md` | 每次改 token/组件/布局必须记 |

冲突裁决顺序：**token → 文档 → 原型 → 截图**。发现冲突，开一个“规范漂移”修复项，不能默默按某一方做。

---

## 2. 变更流程

### 2.1 小改（文案、截图、单个间距）

1. 在 issue/PR 说明改什么、为什么。
2. 改 token（如涉及数值）→ 改原型 → 重新截图。
3. 更新 `CHANGELOG.md` 的 PATCH。
4. 评审清单过一遍。

### 2.2 中改（新增组件、状态、页面）

1. 先写 1 页设计说明：目标、结构、状态、尺寸、对比度、动效、移动端/无障碍。
2. 更新 `01`/`02`/`03` 对应章节。
3. 更新 token（如需要）；新增 token 必须命名语义化。
4. 更新原型/截图；iOS/Android 映射说明。
5. 评审 + 真机验证。
6. `CHANGELOG` 记 MINOR。

### 2.3 大改（换方向、换主色、换布局方向）

1. 先改 `README` 的决策记录（D/O）。
2. 新开一版原型（如 `home-paper-v3.html`），不要直接覆盖基准。
3. 旧版进 `archive/` 或在文档标注“存档”。
4. 全量重测对比度/触控/字号/性能。
5. 评审通过后，更新基准 token/截图/版本号（MAJOR）。
6. 通知所有下游（Android 分支、构建、Release 说明）。

> **禁止**：直接改基准原型但不改 token/文档；只改 token 不重新截图；只改截图不更新原型。

---

## 3. 版本号

采用语义化版本 `MAJOR.MINOR.PATCH`：

| 变更 | 版本 |
|---|---|
| 换视觉方向、主色、布局方向、删除/重命名 token | **MAJOR** |
| 新增组件/状态/页面、新增 token、调整组件尺寸 | **MINOR** |
| 文案、截图、对比度微调、修 bug | **PATCH** |

当前：**2.0.0**（V2 纸质）。V1 深色是 1.x 存档，不再发版。

发布时在 `CHANGELOG.md` 写：日期、版本、变更、影响文件、验证人/设备。

## 4. 评审清单

### 4.1 设计评审（每个新页面/组件）

- [ ] 使用 V2 纸质方向；没有混入 V1 深色/旧 FCL 主题色。
- [ ] 所有颜色/字号/间距/圆角/时长来自 token；没有硬编码。
- [ ] 纸卡/底栏是实色；只有灵动岛有模糊。
- [ ] 只有一个 UI 强调色（苔墨）；淡锈/赭石只在插画。
- [ ] 正文 ≥16、辅助/标签 ≥14；中文无负字距。
- [ ] 对比度 ≥4.5；苔绿点不单独表意。
- [ ] 触控 48/44/54/70；热区不重叠。
- [ ] 默认/按压/焦点/禁用/加载/空/错误齐全或明确“不适用”。
- [ ] 长文本省略；启动按钮不被挤压。
- [ ] 动效 120/480/520；无循环；reduced-motion 有降级。
- [ ] 空/错/载有文案和恢复路径；没有假数据。
- [ ] 截图更新；CHANGELOG 更新。

### 4.2 代码评审（Android/Web）

- [ ] 没有写死 hex/字号/圆角/时长。
- [ ] 文本用 sp；间距/尺寸用 dp。
- [ ] 焦点环不被裁切；读屏有名称。
- [ ] 玻璃 fallback；无模糊设备可用。
- [ ] `WindowInsets` 安全区；状态栏图标正确。
- [ ] 旋转/字号缩放/深浅系统设置不崩。
- [ ] 列表回收/图片内存；无每帧分配。
- [ ] 长按/删除有确认；无静默破坏。
- [ ] 构建通过；真机截图与基准对比。

### 4.3 可访问性评审

- [ ] 对比度实测记录。
- [ ] 触控/焦点/键盘顺序。
- [ ] TalkBack 走查。
- [ ] reduced-motion / transparency / contrast。
- [ ] 字体缩放 1.3×/2.0×。
- [ ] 错误/状态不只靠颜色。
- [ ] 破坏性操作有确认。

## 5. 新页面配方

1. **先定任务**：这个页面只做一件什么事？主操作是什么？
2. **套 Shell**：纸背景 + 内容滚动 + 底栏；只有需要时才加岛（岛是全局 chrome，不是每页都加）。
3. **选组件**：优先复用 02 的组件；不要新造卡片/按钮。
4. **套 token**：颜色/字/间距/圆角/动效全部取 token；不新增 literal。
5. **补状态**：空/载/错/禁用/按压/焦点；每个状态写文案。
6. **测三件事**：对比度、触控、长文本。
7. **截图 + 文档 + CHANGELOG**；评审后再合并。

### 5.1 页面骨架

```text
纸面背景
└── 可滚动内容（16 边距）
    ├── 页头（标题 32 / 副标题 14）
    ├── 页面主内容（纸卡/明信片/列表）
    └── 底部提示（14，ink-3）
└── 固定 chrome
    ├── 灵动岛（仅需要快速启动时）
    └── 纸质底栏（3–5 项）
```

### 5.2 不要

- 不要每个页面都加灵动岛；它是首页/世界上下文的全局 chrome。
- 不要新造第二种卡片圆角/阴影。
- 不要把“设置”做成玻璃列表。
- 不要在下载页再用一个强调色。

## 6. Do / Don't 总表

| Do | Don't |
|---|---|
| 纸底 + 墨字 + 苔墨印 | 紫蓝渐变、霓虹、第二个强调色 |
| 只有灵动岛模糊 | 玻璃卡、玻璃底栏、玻璃明信片 |
| 48/44/54/70 热区 | 40dp 图标按钮、热区重叠 |
| 16/14 字号 | 12/11/8sp、负字距中文 |
| 4.5:1 实测 | 只凭肉眼/设计稿估算 |
| 120ms 按压、无循环 | `transition: all`、无限 shimmer |
| 默认/按压/焦点/禁用/加载/空/错 | 只做默认态 |
| 长文本省略、启动不被挤 | 截断关键信息、按钮被文案挤走 |
| 纸卡单层 | 嵌套卡片、卡内再卡 |
| 空/错有恢复路径 | “出错了”“暂无数据” |
| 真实数据 | 假 KPI、假评价、假下载量 |
| 自有截图/插画 | 官方纹理/皮肤/图标 |

## 7. 决策记录模板

新增/推翻决策时，在 `README` §4/§6 或单独的 `DECISIONS.md` 记录：

```md
### D13 · 底栏保留文字标签
- 日期：2026-11-05
- 状态：已定 / 待定 / 已废弃
- 背景：三个抽象图标需要记忆；纸质底栏有空间。
- 决策：保留 14px 文字标签，图标 + 标签同时存在。
- 影响：底栏高度 72，标签 14/20；不改变触控。
- 备选：只留图标（需重新验证可发现性）。
```

规则：

- 已定决策不要悄悄改；要改就新增一条“替代 Dxx”，保留历史。
- 未决项（O1/O3/O4…）不要写成已定；实现前必须问。
- 决策记录与 CHANGELOG 分开：CHANGELOG 记“什么时候改了什么”，决策记录记“为什么”。

---

## 8. CHANGELOG 规则

每次改动至少一行：

```md
## 2.0.0 — 2026-11-05
### Added
- V2 纸质设计系统：纸/墨/苔墨 token、明信片、乳白玻璃岛、纸质底栏。
- HTML 原型 + 截图 + Android 映射。
### Changed
- 从 V1 深色烟玻璃切换到 V2 纸质（MAJOR）。
### Notes
- 横屏/深色纸/岛展开态仍未决。
```

- 日期用绝对日期；不用“今天/最近”。
- 破坏性变更标 **BREAKING**。
- 关联 issue/PR/commit（如果有）。

## 9. 发布前检查（设计系统）

- [ ] 版本号更新；CHANGELOG 完整。
- [ ] 原型 + 截图与 token 一致。
- [ ] 所有链接可打开；没有失效相对路径。
- [ ] 新增/修改的组件有状态矩阵。
- [ ] 对比度/触控/字号数据在文档里。
- [ ] 未决项没有被写成已定。
- [ ] 真机/浏览器验证记录（尺寸、字号、降级）。
- [ ] 下游通知：Android 分支、构建、Release 说明。

---

## 10. 交接给下一个 AI 的 60 秒

1. 读 `README` §4/§5/§6。
2. 打开 `prototypes/home-paper-v2.html` 和截图。
3. 读 `design-tokens.json`。
4. 读本页 §5 新页面配方 + §4 评审清单。
5. 不要改 O1/O3/O4；先问。
6. 改任何东西：token → 文档 → 原型 → 截图 → CHANGELOG。
