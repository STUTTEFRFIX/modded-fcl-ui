# 03 · 布局与适配

> 390×844 基准、安全区、滚动、断点、横屏策略、字号缩放。
> 当前基准是**竖屏**；横屏未批准。见 [§6](#6-横屏策略未批准)。

---

## 1. 参考画布

| 项 | 值 |
|---|---:|
| 参考宽 | **390** |
| 参考高 | **844** |
| 内容左右边距 | **16** |
| Chrome 左右边距 | **12** |
| 状态栏 | **44**（含安全区上边距） |
| 底栏 | **72 + 安全区下边距** |
| 灵动岛 | **64** |
| 内容底部内边距 | **160** |

390×844 接近 iPhone 13/14 的逻辑尺寸，也接近一加 Ace 2 Pro 的 CSS 宽度。它是**设计基准**，不是唯一支持的尺寸；360/412/430 宽必须能用。

## 2. 纵向节奏

| 区段 | 高度 | 计算 |
|---|---:|---|
| 状态栏 | 44 | `max(env(safe-area-inset-top), 10)` + 内容 + 4；最小 44 |
| 页头 | 98 | 20 上 + 40 标题 + 2 间距 + 20 副标题 + 16 下 |
| 明信片 | 188 | 112 图画 + 74 纸签 + 2 边框 |
| 分组头 | 44 | 16 上边距 + 44 + 12 下边距（合计 72 的区段） |
| 世界行 ×3 | 234 | 70 × 3 + 12 × 2 |
| 提示 | 36 | 16 上边距 + 20 行高 |
| 内容结束 | **672** | 44 + 98 + 188 + 72 + 234 + 36 |
| 灵动岛顶部 | **696** | 844 − 72 底栏 − 12 间距 − 64 岛高 |
| 呼吸 | **24** | 696 − 672 |

### 2.1 明信片

```
188 = 1 边框 + 112 图画 + 74 纸签 + 1 边框
74  = 12 上 + 28 标题 + 2 间距 + 20 元信息 + 12 下
```

### 2.2 内容底部内边距

```
160 = 72 底栏 + 64 岛高 + 24 呼吸
```

短屏滚动时，最后一行/提示必须能滚到灵动岛上方；不要被岛永久遮住。

## 3. 安全区

### 3.1 Web / 原型

```css
padding-top: max(env(safe-area-inset-top, 0px), 10px);
padding-bottom: calc(8px + env(safe-area-inset-bottom, 0px));
```

- `viewport-fit=cover` 必须开。
- 灵动岛底部：`calc(var(--bar-h) + env(safe-area-inset-bottom) + 12px)`。
- 底栏高度：`calc(72px + env(safe-area-inset-bottom))`。
- 内容底部内边距再加 `env(safe-area-inset-bottom)`（原型已含在 160 里；实现时按实际安全区加）。

### 3.2 Android

- 用 `WindowInsetsCompat` / `ViewCompat.setOnApplyWindowInsetsListener`；
- 底栏 `paddingBottom += navigationBars.bottom`；
- 内容 `paddingBottom = barHeight + islandHeight + 24 + navigationBars.bottom`；
- 状态栏：浅色纸面 → `WindowInsetsControllerCompat.isAppearanceLightStatusBars = true`（深色图标）；
- 不要用固定 `60dp`/`80dp` 猜安全区。

### 3.3 刘海/挖孔/手势条

- 内容不得被挖孔/手势条遮住；顶部至少 10dp 呼吸。
- 手势导航下底栏高度增加，标签仍要离屏幕底 ≥8dp。
- 不要画一条假状态栏盖住系统状态栏。

## 4. 滚动

- **只有内容滚动**；岛和底栏是 fixed/absolute。
- 内容 `overscroll-behavior: contain`；不让整页弹跳。
- 滚动条隐藏（`scrollbar-width:none` / `::-webkit-scrollbar{display:none}`）；不要自定义粗滚动条。
- 内容底部内边距 160；短屏可滚，长屏不滚。
- 切换底栏 tab 时保留各自滚动位置（原生实现）。
- 不要把灵动岛做成 `position: sticky` 跟着内容走；它固定在底栏上方。

## 5. 宽度与断点

| 宽度 | 行为 |
|---:|---|
| 320–359 | 内容 16 边距；标题可缩到 28/36；岛信息块可能省略加载器更多字符；底栏标签仍 14；测 320×640 |
| 360–389 | 正常布局；最接近 360×740 的常见 Android |
| **390–430** | 设计基准；按 390 的尺寸 |
| 431–599 | 内容仍单列，最大宽度 **430** 居中；不要拉宽岛/卡 |
| ≥600 | 桌面/平板：显示 390×844 手机框居中（当前原型行为）；不做拉伸布局 |
| 横屏 | **未批准**；见 §6 |

### 5.1 内容最大宽度

- 手机单列内容最大 **430**；更宽时居中，两侧留纸面。
- 灵动岛最大宽度跟随内容宽度 + 8（左右各少 4）；不要让岛在平板上横贯 1000px。
- 底栏在手机全宽；平板/桌面框内仍 390 宽。

### 5.2 短屏

- 360×740 时内容总高 672 会超过可视区（672 + 底栏/岛区域 > 740），进入滚动；
- 内容底部 160 保证最后一行能滚到岛上方；
- 不要把明信片压缩到 150 以下来“塞下”；宁可滚动。

## 6. 横屏策略（未批准）

> **O1 未决**：FCL 上游是 `sensorLandscape` 横屏壳；本规范按竖屏设计。横屏不是“把竖屏拉宽”。

### 6.1 不要做

- 不要把 390 布局横向拉伸到 844 宽。
- 不要把底栏横在底部拉成 844 宽、岛也拉成 844 宽。
- 不要直接把底栏改成左侧竖栏却不改内容分区。

### 6.2 如果产品决定横屏，推荐方向（待评审）

**方案 A：左侧竖栏 + 底部岛**

```
┌──────┬──────────────────────────────┐
│ 首页 │  内容（明信片 + 世界行）       │
│ 下载 │                              │
│ 设置 │                              │
│      │  ┌────────────────────────┐  │
│      │  │ 灵动岛（底部居中，420） │  │
│      │  └────────────────────────┘  │
└──────┴──────────────────────────────┘
```

- 左侧 88dp 竖栏，图标 + 14 标签；选中苔绿印；
- 内容左右 24；明信片 16:9 或 240 高；
- 岛底部居中，宽 420，距底 16；仍然只有岛是玻璃；
- 底栏不再是 28 上沿纸条，而是 88 宽的纸栏（结构材质）。

**方案 B：双栏**

- 左列 40% 世界列表，右列 60% 明信片/详情；
- 岛在底部居中；底栏在左列底部或左栏竖排；
- 适合平板/横屏，但信息密度更高，需要重新设计。

**无论哪个方案**：颜色/字体/间距/圆角/材质 token 不变；必须补页面级布局文档、截图、对比度/触控验收，再实现。

## 7. 动态字号与缩放

| 字号缩放 | 行为 |
|---|---|
| 1.0× | 基准 |
| 1.15× | 标题可换行；行高增长；岛仍 64 |
| 1.3× | 岛可长到 **72**；底栏可长到 **80**；世界行可长到 78；明信片纸签可长到 82 |
| 2.0× | 允许两行标题；元信息可换行；岛信息块两行仍不裁切；启动热区 ≥48 |

规则：

- Android 用 `sp`；Web 用 `rem`/浏览器缩放；禁止 `user-scalable=no`。
- 字号放大优先增高度/换行，不缩小字号、不截断关键信息。
- 岛/底栏高度变化时，内容底部内边距同步增加（用 `dp` + 实际测量，不要写死 160）。
- 真机测 1.0 / 1.3 / 2.0；至少 360×740 与 390×844 两档。

## 8. 密度、资源与层叠

### 8.1 资源

- 图标/插画用矢量（SVG/VectorDrawable）；截图/照片用 1x/2x/3x。
- 不引网络图片；纸张纹理用 CSS/SVG。
- 位图不超过 2x 显示尺寸的 2 倍；避免大图内存。

### 8.2 z-index

| 层 | 值 |
|---|---:|
| 背景 | 0 |
| 内容 | 1 |
| 岛/底栏 | 30 |
| 纸纤维 | 50 |
| 弹层 | 60 |
| 系统 UI | 系统管理 |

- 纸纤维层 `pointer-events:none`；不能挡住点击。
- 弹层必须在纤维层之上，否则会被噪点“盖住”而显得脏。
- 不要用 9999 这种魔法 z-index。

### 8.3 阴影/发光

- 只用暖灰阴影；不加彩色 glow。
- 阴影不改变布局（不要用 `filter: drop-shadow` 影响测量）。
- 玻璃的阴影比纸卡深，但不能黑到发脏。

## 9. 布局验收清单

- [ ] 390×844 下：内容结束 672、岛顶 696、呼吸 24。
- [ ] 360×740 下：能滚动，最后一项能滚到岛上方；不被永久遮挡。
- [ ] 320×640 下：文字不裁切；岛启动按钮不被挤压；底栏标签可读。
- [ ] 安全区：刘海/手势条下不遮内容；底栏标签离底 ≥8。
- [ ] 内容最大宽 430 居中；平板不拉伸。
- [ ] 字号 1.3×/2.0× 不裁切；岛/底栏按合同增高。
- [ ] 只有内容滚动；岛/底栏固定；滚动条隐藏。
- [ ] z-index：纤维不挡点击；弹层在未来高于纤维。
- [ ] 横屏没有被“顺手拉宽”；O1 未决时不做横屏实现。
