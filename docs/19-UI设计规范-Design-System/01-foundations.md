# 01 · 基础规范

> 色彩、字体、间距、圆角、材质、图标、动效、图像。
> 所有数值必须与 [`design-tokens.css`](design-tokens.css) / [`design-tokens.json`](design-tokens.json) 一致；本文解释“为什么”和“怎么用”。

---

## 1. 色彩

### 1.1 原则

1. **纸是底，墨是字，苔绿是印。** 画面里 80% 以上应该是纸和墨；苔绿只出现在“当前 / 选中 / 主操作”这三类位置。
2. **不用纯黑纯白。** 纸不是 `#FFFFFF`，墨不是 `#000000`；白色只以玻璃高光/纸边的 `rgba(255,255,255,…)` 出现。
3. **一个 UI 强调色。** 淡锈、赭石、鼠尾草只属于内容插画和缩略图，不得变成按钮/导航/链接色。
4. **颜色不单独承担状态。** 选中、错误、禁用必须同时有文字/图标/形状/位置变化。

### 1.2 纸与墨

| Token | 值 | 角色 | 预期背景 | 对比度 | 用法 |
|---|---|---|---:|---:|---|
| `--paper-0` | `#F1EEE6` | 纸面顶部 | — | — | 屏幕顶部底色 |
| `--paper-1` | `#EAE6DB` | 纸面中部 | — | — | 中部过渡 |
| `--paper-2` | `#E2DDD1` | 纸面底部 | — | — | 底部过渡、纸边 |
| `--card` | `#F8F6EF` | 纸卡 / 明信片 | — | — | 主视觉、列表卡 |
| `--ink` | `#2C2E28` | 主文字 | `--card` | **12.70:1** | 标题、行标题、版本号 |
| `--ink` | 同上 | 主文字 | `--paper-0` | **11.85:1** | 页面标题、正文 |
| `--ink-2` | `#55584C` | 次级文字 | `--card` | **6.73:1** | 分组标题、强调元信息 |
| `--ink-3` | `#5F6256` | 辅助文字 | `--card` | **5.77:1** | 元信息、提示、未选中导航 |
| `--ink-3` | 同上 | 辅助文字 | `--paper-2` | **4.60:1** | 纸面最暗处的辅助文字（底线） |
| `--line` | `rgba(74,68,54,.14)` | 发丝边 | — | 装饰 | 纸卡/明信片边框 |
| `--line-strong` | `rgba(74,68,54,.24)` | 强边 | — | 装饰 | 按压/悬停边框 |

> 边框是装饰，不承担控件识别；控件识别靠文字、阴影、形状和焦点环。**不要**用 1.93:1 的 `--line-strong` 当输入框边框并声称满足 3:1。

### 1.3 苔绿

| Token | 值 | 角色 | 预期背景 | 对比度 | 用法 |
|---|---|---|---:|---:|---|
| `--accent` | `#7F9470` | 苔绿点 / 装饰 | `--card` | 3.05:1 | 6px 状态点、插图点缀；**不是文字色** |
| `--accent-ink` | `#4C6143` | 苔墨（UI 强调） | `--card` | **6.27:1** | 选中图标/文字、焦点环、启动按钮底 |
| `--accent-ink` | 同上 | 苔墨 | `--accent-wash` | **5.38:1** | 底栏选中态 |
| `--accent-wash` | `#E2E7D8` | 苔绿淡印 | — | — | 底栏选中胶囊、未来浅色状态底 |
| `--on-accent` | `#F8F3E7` | 苔墨上的图标 | `--accent-ink` | **6.12:1** | 启动按钮的 play 图标 |

**硬规则**：

- `--accent` 在纸面上的对比度只有 2.84–3.05:1，**不能当文字色**，也不能单独作为状态指示。
- 状态点必须和文字一起出现（如“当前世界”+ 点）；没有文字的纯色点不得单独传达“已选中/错误”。
- 苔绿不得用来给大面积纸卡染色；最多是 52×30 的选中印和 6px 的点。

### 1.4 语义状态色（保留，不在当前首页使用）

| Token | 值 | 搭配底 | 对比度 | 用法 |
|---|---|---|---:|---|
| `--error` | `#8C4F3F` | `--error-surface #F0E2DA` | 5.02:1 | 错误文字/图标；必须配文字 |
| `--warning` | `#7A5A32` | `--warning-surface #F2E8D6` | 5.18:1 | 警告；必须配文字/图标 |
| `--success` | `#4C6143` | `--accent-wash` | 5.38:1 | 成功/已完成；与苔墨同值，避免多一套绿 |
| `--info` | `#4E5A66` | `--info-surface #E7EBEE` | 6.52:1（对纸卡） | 中性提示；不得变成第二个强调色 |

**规则**：

- 语义色只用于状态，不做装饰；不得同时出现两个以上语义色。
- 错误/警告不得只靠颜色：必须有“错误/失败/注意”文字或图标。
- 当前 V2 首页没有错误/警告；这些 token 是给后续下载/设置/启动失败用的。未设计页面不得擅自使用。

### 1.5 内容插画色（不是 UI token）

| 名称 | 值 | 用在哪 |
|---|---|---|
| 淡锈 | `#A8795E` | 红石缩略图、太阳插图 |
| 赭石 | `#C3935A` | 沙岩缩略图、暖窗 |
| 鼠尾草 | `#8FA37C` / `#78886B` / `#5E6E56` | 山谷、草地、树 |
| 土色 | `#8A6F55` / `#7A5D47` | 空岛土块、木屋 |
| 纸云 | `#F7F3E9` | 云、窗光 |

**规则**：这些颜色只允许出现在 SVG 插画、缩略图、内容图片里；不得变成按钮、选中态、链接、边框。

### 1.6 状态层

| 状态 | 纸面叠加 | 说明 |
|---|---|---|
| Hover（仅精细指针） | `rgba(74,68,54,.04–.05)` | 不改变布局；触屏不做粘滞 hover |
| Pressed | `rgba(74,68,54,.05–.08)` 或 `scale(.94–.95)` | 120ms；行用底色，图标按钮用缩放 |
| Focus-visible | `2px solid var(--accent-ink)`，offset 3 | 启动按钮用 `--ink` 环，offset 2 |
| Disabled ink | `rgba(44,46,40,.38)` | 视觉可读但明确不可用 |
| Disabled surface | `rgba(44,46,40,.06)` | 不改变文字对比度到不可读 |
| Selected | 苔墨文字/图标 + `--accent-wash` 底 | 同时有文字/图标变化 |

### 1.7 禁止

- 紫蓝渐变、霓虹辉光、彩色光晕、emoji 当图标。
- 纯黑 `#000000`、纯白 `#FFFFFF` 画布。
- 第二个 UI 强调色；把淡锈/赭石用在按钮/导航上。
- 用颜色单独表示选中/错误/禁用。
- 用 `--accent` 当文字色。
- 用低对比边框假装控件边界满足 3:1。

### 1.8 深色 / 夜间

**未设计。** 不要自动反相、不要把 V1 深色版当夜间主题。后续应做“炭纸/牛皮纸”变体：同一套间距/圆角/苔墨逻辑，重新定义纸与墨的明度，并重新测对比度。见 `README` O4。

## 2. 字体

### 2.1 字体族

```css
font-family: system-ui, -apple-system, "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
```

- 不引入外部字体；不下载 Inter/Fraunces/Playfair 等黑名单字体。
- Android 使用系统字体（Roboto / Noto Sans CJK / OEM 字体）；OEM 替换可能导致字宽变化，必须用真机复核截断。
- 中文不做负字距；拉丁字母/数字可用 `0.01em` 轻微正字距。

### 2.2 字号阶梯

| 角色 | 字号 / 行高 | 字重 | 用在哪 | 最小场景 |
|---|---|---|---:|---|
| 页面标题 | **32 / 40** | 600 | 「世界」 | 390 宽；不可再大 |
| 主视觉标题 | **22 / 28** | 600 | 「生存存档」 | 明信片纸签 |
| 正文 / 列表标题 | **16 / 24** | 400 / 500 | 世界名 | 行标题 500，正文 400 |
| 辅助 / 元信息 | **14 / 20** | 400 | 版本、加载器、上次游玩 | 不得低于 14 |
| 标签 / 导航 | **14 / 20** | 500 | 底栏、chip、按钮 | 不得低于 14 |
| 灵动岛版本 | **16 / 20** | 600 | `1.21.5` | 固定一行 |
| 灵动岛加载器 | **14 / 18** | 400 | `Fabric 0.16.9` | 固定一行 |
| 状态栏 | **14 / 20** | 600 | 仿制时间/电量 | 真实 App 用系统 |

> 行高是字号角色的一部分，不要单独改。中文正文行高 1.5 左右；标题 1.25–1.3。

### 2.3 中文规则

1. **不做负字距**：中文标题 `letter-spacing: 0`；不要套 -0.03em。
2. **不做全大写英文标题**；标签用正常大小写。
3. **不要用两端对齐**；左对齐。
4. **避免孤字/孤行**：标题最多 2 行；元信息 1 行，超长用 `…`。
5. **数字用 tabular-nums**（版本号、时间、计数），避免跳动。
6. **中英文混排**：版本号/加载器保留英文原名；中文与英文之间不强制加空格，但文案要通顺。

### 2.4 字重

只用 **400 / 500 / 600**：

- 400：正文、元信息、加载器。
- 500：列表标题、标签、底栏、chip。
- 600：页面标题、主视觉标题、版本号、状态栏。
- 不使用 700+；不使用伪粗体；不要用字号代替字重做层级。

### 2.5 截断

| 位置 | 规则 |
|---|---|
| 页面标题 | 最多 2 行；不截断 |
| 主视觉标题 | 1 行；`…` |
| 主视觉元信息 | 1 行；`…` |
| 世界行标题 | 1 行；`…` |
| 世界行元信息 | 1 行；`…`；分隔符 ` · ` |
| 灵动岛版本 | 1 行；`…`；启动按钮不被挤压 |
| 灵动岛加载器 | 1 行；`…` |
| 底栏标签 | 1 行；2–4 个汉字最佳 |

`.world-copy` 必须是 `min-width: 0` + `flex: 1`；否则 `ellipsis` 不生效。灵动岛信息块同理。

### 2.6 动态字号

- Android 用 `sp`，Web 用 `rem` 或允许浏览器缩放；**禁止** `user-scalable=no` / `maximum-scale=1`。
- 1.3× / 2.0× 字号下：标题允许换行；世界行高度可增长；灵动岛可从 64 长到 72；底栏可从 72 长到 80；不得裁切文字。
- 字号放大时优先增加高度/换行，不缩小字号、不截断关键信息。
- 真机至少测 1.0 / 1.3 / 2.0 三档。

### 2.7 压印字

- 只允许在 **页面标题 / 主视觉标题 / 灵动岛版本** 上加 `text-shadow: 0 1px 0 rgba(255,255,255,.5)`。
- 这是纸面压印，不是投影；不要用深色阴影、不要用多层描边。
- 正文/元信息不加 text-shadow。

## 3. 间距

### 3.1 阶梯

以 **4px** 为基数：

| Token | 值 | 典型用途 |
|---|---:|---|
| `--space-1` | 4 | 图标内边、微调 |
| `--space-2` | 8 | 图标按钮内边、底栏内边 |
| `--space-3` | 12 | 卡片内边、岛内边、行间距 |
| `--space-4` | 16 | 内容左右边距、卡片上下 |
| `--space-5` | 20 | 页头上边距 |
| `--space-6` | 24 | 内容底部呼吸、岛与内容 |
| `--space-7` | 32 | 大区块（暂未用） |
| `--space-8` | 40 | 页面级（暂未用） |

### 3.2 布局常量

| 常量 | 值 | 说明 |
|---|---:|---|
| 内容左右边距 | 16 | 所有内容卡的左线 |
| chrome 左右边距 | 12 | 灵动岛比内容宽 4 |
| 状态栏 | 44 | 含安全区上边距 |
| 页头 | 98 | 20 + 40 + 2 + 20 + 16 |
| 明信片 | 188 | 112 画 + 74 纸签 + 2 边框 |
| 分组头 | 44 | 上下 16 / 12 |
| 世界行 | 70 | 44 缩略图 + 12 内边 + 2 边框 |
| 灵动岛 | 64 | 底栏上方 12 |
| 底栏 | 72 + 安全区 | 上沿 28 圆角 |
| 内容底部内边距 | 160 | 72 + 64 + 24 |

### 3.3 微间距

- 文本块内部（标题与元信息）允许 **2px** 行间；这是唯一的 2px 例外。
- 不允许 10 / 11 / 14 / 18 这类“看起来差不多”的间距；要么 8，要么 12/16。
- 组件之间用 12/16；页面区块之间用 16/20/24。

## 4. 圆角与形状

### 4.1 同心圆角

| Token | 值 | 用在哪 |
|---|---:|---|
| `--radius-thumb` | **12** | 44 缩略图、40 草方块图标 |
| `--radius-row` | **16** | 世界纸卡 |
| `--radius-postcard` | **20** | 明信片 |
| `--radius-bar` | **28** | 底栏上沿 |
| `--radius-pill` | **999** | 灵动岛、chip、指示胶囊 |

规则：

- 按容器尺寸递减：28（大结构）→ 20（大卡）→ 16（行）→ 12（小图）→ pill（胶囊）。
- 同一元素的所有角一致；不要只圆上面两个角（底栏上沿是唯一例外，因为它是贴底的纸）。
- 按钮圆形（启动/图标按钮）用 50%；胶囊用 999。
- 不要用 4/6/8 的卡片圆角；不要随手 `border-radius: 10px`。

### 4.2 形状语义

| 形状 | 语义 |
|---|---|
| 胶囊（pill） | 浮动、可扫读的功能条 / 标签 |
| 圆（circle） | 单动作、图标按钮、启动 |
| 大圆角纸卡（16/20） | 内容容器 |
| 贴底纸上沿（28） | 结构层底栏 |

> 圆角不是装饰；它告诉用户“这是浮动的”还是“这是纸上的”。不要给纸卡加胶囊圆角，也不要把灵动岛做成方角。

## 5. 材质与高度

### 5.1 材质层级

| 层 | 材质 | 是否模糊 | 高度 | 例子 |
|---|---|---|---|---|
| 0 | 纸面 | 否 | 0 | 屏幕背景 |
| 1 | 纸卡 | 否 | 1（暖影） | 明信片、世界行 |
| 2 | 纸质底栏 | 否 | 2（向上影） | 底栏 |
| 3 | 乳白玻璃岛 | **是（唯一）** | 3（暖影 + 白边） | 灵动岛 |
| 4 | 弹层/对话框（未来） | 否 | 4（纸面 + scrim） | 管理菜单 |

### 5.2 纸卡

```css
background: linear-gradient(180deg, #FAF8F2, #F4F1E8);
border: 1px solid rgba(74, 68, 54, .14);
box-shadow:
  0 4px 12px rgba(70, 62, 48, .08),
  inset 0 1px 0 rgba(255, 255, 255, .75);
```

- 明信片可以用更深的 `0 12px 26px rgba(70,62,48,.12)`；世界行用 `0 4px 12px`。
- 阴影是**暖灰**，不是黑色；不要用 `rgba(0,0,0,.3)` 的重阴影。
- 内高光 1px，模拟纸张上边缘接光；不要做多层内阴影。

### 5.3 纸底栏

```css
background: linear-gradient(180deg, #F6F3EA, #EFEBE1);
border-top: 1px solid #D6D0C1;
box-shadow:
  0 -10px 24px rgba(80, 70, 55, .10),
  inset 0 1px 0 #FFFDF8,
  inset 0 -1px 0 rgba(100, 90, 70, .06);
```

- **禁止** `backdrop-filter`；底栏是结构层，必须实。
- 上沿 28 圆角；底部随屏幕裁切；安全区加在高度里。

### 5.4 乳白玻璃岛

```css
background: linear-gradient(145deg, rgba(252,249,242,.64), rgba(238,233,222,.72));
backdrop-filter: blur(26px) saturate(115%);
border: 1px solid rgba(255,255,255,.78);
box-shadow:
  inset 0 1px 0 rgba(255,255,255,.92),
  inset 0 -1px 0 rgba(120,105,85,.08),
  0 14px 32px rgba(80,70,55,.18);
```

- **整屏唯一允许模糊的层**。不要再给纸卡、底栏、明信片加 `backdrop-filter`。
- 玻璃上的文字必须用 `--ink` / `--ink-3`，对比度按有效底色（约 `#F2EEE5`）测。
- 不支持模糊：`background: #F7F4EC` 实色；`prefers-reduced-transparency` 同样。
- 模糊半径 26px；不要为了“更玻璃”加到 40px；不要动画模糊半径。

### 5.5 高度（阴影）规则

- 纸卡：0 4/12 或 0 12/26；底栏：向上 10/24；岛：14/32。
- 阴影只表达“浮起”，不表达层级顺序；不要给每张卡不同阴影。
- 深色主题未设计前，不要在纸面上用黑色重阴影。

### 5.6 禁止

- 玻璃卡、玻璃底栏、玻璃明信片。
- 卡片套卡片；明信片里再放一张纸卡。
- 霓虹光晕、彩色投影、零偏移彩色 glow。
- 用纯黑阴影。
- 用 `backdrop-filter` 做“高级感”；它只属于灵动岛。

## 6. 图标

### 6.1 规格

| 类型 | 尺寸 | 描边 | 端点 | 用在哪 |
|---|---:|---:|---|---|
| 主图标 | 24 | 1.8 | round | 底栏、账户 |
| 小箭头 | 16 | 2.0 | round | 列表/“全部”右侧 |
| 更多点 | 20（3×1.5 圆） | 填充 | — | 明信片 more |
| Play | 22 | 填充 | — | 启动 |
| 状态栏 | 12–24 | 1.2–1.6 | round | 仅设计稿仿制 |

### 6.2 图标集（当前）

- 首页：带门洞的房子。
- 下载：托盘 + 下箭头。
- 设置：两条推子（不是齿轮）。
- 账户：线性人像。
- 更多：三个填充点。
- 箭头：右向单箭头。
- 启动：圆角三角。

全部是手绘 SVG `<symbol>`；不引图标库、不用 emoji、不用 Material baseline 图标、不混用填充/描边（Play/更多点是有意的填充按钮内容）。

### 6.3 规则

- 图标必须有可访问名称（按钮 `aria-label` / Android `contentDescription`）；纯装饰图标 `aria-hidden`。
- 视觉尺寸可以小于热区；热区按 §02 组件表。
- 图标不得单独承担关键状态；选中态同时改文字颜色/底。
- 不要拉伸图标；保持正方形 viewBox。
- 不要用图标字体；不要从网络加载图标。

## 7. 动效

### 7.1 时长与曲线

| 场景 | 时长 | 曲线 |
|---|---:|---|
| 按压 | **120ms** | `cubic-bezier(.23,1,.32,1)` |
| 颜色/状态 | 200–240ms | 同上 |
| 岛/底栏入场 | 480 / 520ms（底栏延迟 60ms） | 同上 |
| 底栏指示胶囊 | opacity 200ms / transform 260ms | 同上 |
| 页面转场（未来） | 240–300ms | 同上 |
| 模态/弹层（未来） | ≤500ms | 同上 |

### 7.2 允许动画的属性

- `transform`（scale / translate）
- `opacity`
- 颜色（color / background-color / border-color）

**禁止**：`width` / `height` 与 `backdrop-filter` 同时动画；`transition: all`；`@keyframes` 循环；无限 shimmer（除非是 loading，见 §7.5）。

### 7.3 按压

- 图标按钮/启动：`scale(.94–.95)`，120ms；启动同时 `filter: brightness(.96)`。
- 世界行/底栏项：用底色/边框状态，不用整体缩放（行太大会晃）。
- 触屏没有 hover；`@media (hover:hover) and (pointer:fine)` 才做 hover。
- 按压反馈在 pointer-down 就出现，不等 click。

### 7.4 入场

- 灵动岛：opacity 0→1 + translateY(9px→0)，480ms。
- 底栏：opacity 0→1 + translateY(9px→0)，520ms，延迟 60ms。
- 只在首次载入做一次；不要每次 tab 切换都重播。
- 不做 blur 动画；不做宽度展开动画。

### 7.5 加载（未来）

- loading 可以用 1 个循环指示器（仅 loading 场景），但必须尊重 reduced-motion，且不能整页闪烁。
- 启动中的按钮建议变成同尺寸的环形进度/静态“启动中…”文字；不要用彩虹/霓虹 spinner。

### 7.6 reduced-motion

- 关闭入场位移/缩放、按压缩放、指示胶囊位移；保留颜色/透明度变化（200ms 线性）。
- Android 读取 `Settings.Global.ANIMATOR_DURATION_SCALE` / `ValueAnimator.areAnimatorsEnabled()`；为 0 时不要播放位移动画。
- 不用 `animation: none !important` 一刀切；保留必要的状态反馈。

### 7.7 性能

- 只动合成属性；玻璃只一处；避免每帧 `setState`。
- 纸上全屏噪点/帘纹是静态层，不参与动画。
- 未来原生手势用 spring（阻尼 1.0、response 0.3–0.4 为默认），只有带速度交接才允许轻微回弹。

| 纸底 | `#F1EEE6 → #E2DDD1` | 主色 | 竖向微渐变 |
