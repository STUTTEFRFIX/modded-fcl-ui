# 02 · 组件合同

> 每个组件的尺寸、颜色、状态、行为和可访问性。
> **已实现** = 当前 `home-paper-v2.html` 中有；**合同** = 规范已定义、原型未实现，后续实现必须按此做。
> 所有数值必须来自 [`design-tokens.css`](design-tokens.css) / [`design-tokens.json`](design-tokens.json)。

---

## 0. 通用规则

1. 组件只能使用 token；不得写死颜色/字号/圆角/时长。
2. 每个可交互组件必须定义：默认 / 按压 / 焦点 / 禁用 / 加载 / 空 / 错误（不适用的状态写“不适用”，不能空白）。
3. 可点区域 ≥44×44；主启动 ≥48×48。
4. 焦点环：`2px solid var(--accent-ink)`，offset 3；启动按钮用 `2px solid var(--ink)`，offset 2。
5. 触屏不做粘滞 hover；hover 只在 `(hover:hover) and (pointer:fine)`。
6. 图标按钮必须有可访问名称；装饰图标 `aria-hidden` / `importantForAccessibility=no`。
7. 所有文字截断用省略号，不用裁切；容器 `min-width:0`。

## 1. App Shell

### 1.1 分层

| 层 | z-index | 内容 | 说明 |
|---|---:|---|---|
| 背景 | 0 | 纸底、柔光、帘纹、水印、纸边 | `.backdrop` |
| 内容 | 1 | 可滚动的主内容 | `.content` |
| 固定 chrome | 30 | 灵动岛、底栏 | `.island` / `.tabbar` |
| 纸纤维 | 50 | 全屏噪点，`pointer-events:none` | `.screen::after` |
| 未来弹层 | 60 | 管理菜单、对话框 | 必须在纤维层之上 |

### 1.2 滚动

- 只有 `.content` 滚动；岛和底栏固定。
- 内容底部内边距 **160px**（72 底栏 + 64 岛 + 24 呼吸 + 安全区）。
- 短屏时内容从岛下经过；最后一项必须能滚到岛上方，不能被永久遮住。
- 不使用整页滚动；`overscroll-behavior: contain`。

## 2. 灵动岛（Quick Launch Island）

### 2.1 解剖

```
┌──────────────────────────────────────────┐
│ [草方块]  1.21.5                  ( ▶ )  │
│ 40×40     Fabric 0.16.9          48 热区  │
│           版本 16/20/600                 │
│           加载器 14/18/400               │
│ ←12→ ←gap 12→ ←—— flex 1 ——→ ←12→      │
└──────────────────────────────────────────┘
高 64 · 左右 12 · 距底栏 12 · 内边距 12 · 胶囊
```

### 2.2 尺寸

| 项 | 值 | 说明 |
|---|---:|---|
| 岛高 | **64** | 可变高度合同：字号 1.3×+ 时可到 72 |
| 左右外边距 | **12** | 比内容 16 宽 4；chrome 层 |
| 距底栏 | **12** | 底栏上沿到岛下沿 |
| 内边距 | 左右 **12** | 上下由内容居中 |
| 图标 | **40 × 40**，圆角 12 | 草方块；1px 奶油边 |
| 信息块 | flex 1，min-width 0 | 两行，gap 2 |
| 版本 | **16 / 20 / 600** | `--ink`；1 行省略 |
| 加载器 | **14 / 18 / 400** | `--ink-3`；1 行省略 |
| 启动按钮 | 热区 **48 × 48**，视觉 **44** 圆 | `::before` inset 2 |
| 图标–信息块 | 12 | |
| 信息块–按钮 | 12 | |
| 圆角 | pill 999 | |
| 模糊 | 26px / saturate 115% | 唯一玻璃 |

### 2.3 材质

见 [`01-foundations.md`](01-foundations.md) §5.4。要点：

- 乳白玻璃：`.64 → .72` 填充、白边 `.78`、暖影、内侧上高光。
- 顶部 115° 柔光（`::after`，36%→0%），不做强高光。
- 不支持模糊/减少透明：实色 `#F7F4EC`。
- 玻璃上的文字必须是墨色；不要用白字。

### 2.4 内容层级

1. **世界图标**：身份；和明信片同一世界的草方块。
2. **版本**：第一眼信息；16/600。
3. **加载器**：第二眼信息；14/400，位于版本下方。
4. **启动**：唯一主操作；右端；苔墨印章。

> 需求原文是“图标、版本、加载器、启动”从左到右。实现为 **图标 → 版本/加载器（同一信息块上下两行）→ 启动**；四类信息的顺序没变，但中间两块合成一个信息块，避免 390px 下四列互相挤。不要为了“严格四列”把版本和加载器拆成两个同权重列。

### 2.5 状态

| 状态 | 视觉 | 行为 | 状态 |
|---|---|---|---|
| 默认 | 如上 | 点启动才触发 | 已实现 |
| 启动按压 | 启动 `scale(.94)` + `brightness(.96)`，120ms | 松手后进入加载（未来） | 已实现按压；加载为合同 |
| 焦点 | 启动 2px `--ink` 环，offset 2 | 键盘可达 | 已实现 |
| 加载中（合同） | 启动变同尺寸环形进度；加载器行可显示“启动中…” | 禁用重复点击；失败回默认并提示 | 合同 |
| 加载器缺失（合同） | 加载器行 `--error` + 6px 锈点 + “加载器缺失”；启动禁用 | 启动不可点；去世界详情修复 | 合同 |
| 无选中世界（合同） | **不渲染岛** | 首页显示空态；底栏保留 | 合同 |
| 长文本 | 版本/加载器各自 1 行省略；启动不被挤压 | 信息块 `min-width:0` | 已实现 |
| 减少透明 | 实色 `#F7F4EC`，无模糊 | 文字对比不变 | 已实现 |

**禁用样式（合同）**：启动视觉圆用 `rgba(44,46,40,.06)` 底，play 图标 `rgba(44,46,40,.38)`，无阴影/按压；不要只降低透明度到看不见。

### 2.6 行为

- **只有启动按钮可点**；信息块不是按钮（原型没有展开态）。
- 启动点击：一次只触发一次；加载中忽略重复点击。
- 点击信息块：**当前不响应**。V3 若做展开态，必须新增状态合同，用原生 spring，不允许 CSS 宽高 + 模糊动画。
- 长按：不绑定；不要和“长按世界管理”冲突。
- 无障碍：
  - 区域 `aria-label="当前世界快速启动"`。
  - 启动 `aria-label="启动 {世界名}：Minecraft {版本}，{加载器}"`。
  - 版本/加载器文字可读；图标 `aria-hidden=true`。
  - 加载中 `aria-label="正在启动 {世界名}"`；失败用 `aria-live` 提示。

### 2.7 不要

- 不要做成 Apple 的纯黑岛；这不是摄像头挖孔，是纸上的功能层。
- 不要给岛再加一层玻璃/卡片。
- 不要在岛里塞世界名、模组数、内存、账号；V2 只保留四类信息。
- 不要用宽度/高度动画展开；不要在玻璃上做循环 shimmer。
- 不要把版本/加载器拆成两列同权重。
- 不要用 `--accent` 当文字色。

### 2.8 验收

- [ ] 64/12/12/12/40/48/44 全部到位。
- [ ] 版本 16/600、加载器 14/400；两行不换行，超长省略。
- [ ] 启动 48 热区、44 视觉；play 居中，苔墨底奶油图标。
- [ ] 玻璃只有这一处；实色 fallback 生效。
- [ ] 启动按压/焦点/禁用/加载状态齐全（或明确标为合同）。
- [ ] 对比度：版本 11.87:1、加载器 ≥5.5:1。

### 3.2 尺寸

| 内边距 | 8 8 (8 + safe) |

### 3.3 状态

| 状态 | 视觉 | 状态 |
|---|---|---|
| 默认（未选中） | 墨灰图标/标签 | 已实现 |
| 选中 | 苔绿印 + 苔墨图标/标签 | 已实现 |
| 按压 | 整项底色 `rgba(74,68,54,.05)` | 已实现 |
| 焦点 | 2px 苔墨环，offset 3 | 已实现 |
| 禁用 | **不适用**：顶级目的地不要禁用；不可用的页面用页面级空/错态 | 合同 |
| 加载 | 不适用（页面自己加载） | — |
| 错误 | 不适用（页面自己报错） | — |

### 3.4 行为

- 点击切换选中 + `aria-current="page"`；页面切换由原生/路由负责。
- 底栏不做滑动切换；不做长按；不做双击。
- 每个 tab 保留自己的滚动位置（原生实现时）；返回 tab 不重置。
- 徽标（未来）：16/14，苔墨/锈色，必须有文字或数字；不能只放一个色点。

### 3.5 无障碍

- `<nav aria-label="主导航">`；每个按钮有 14px 可见标签。
- 选中项 `aria-current="page"`；未选中不设。
- 图标 `aria-hidden`；标签是名称。
- 3–5 项；当前 3 项；少于 3 或多于 5 都违反 MD3/导航常识。

### 3.6 不要

- 不要把底栏做成玻璃、浮动 pill、或再加一层 blur。
- 不要只用图标不留标签（当前决策保留标签；如要改，先更新 O2）。
- 不要用第二个强调色做选中。
- 不要把选中胶囊做成整条底栏高亮。

| 底 | 透明；不加胶囊 |

### 6.4 按钮通用规则

- 按“动作重要性”选：主启动（实心苔墨）> 图标按钮（纸）> 文字按钮（无底）。
- 一屏最多一个实心主按钮。
- 所有按钮 120ms 按压；触屏没有 hover。
- 焦点环不能裁切（不要放在 `overflow:hidden` 的容器里）。
- 按钮的 `aria-label` 说清动作对象；不要只写“确定”。

## 7. Chip 与标签

### 7.1 当前世界 Chip（非交互）

| 项 | 值 |
|---|---:|
| 高 | 28 |
| 内边距 | 0 12 |
| 圆角 | pill |
| 字 | 14 / 20 / 500 |
| 底 | `rgba(250,247,240,.92)` |
| 边 | 1px `rgba(74,68,54,.18)` |
| 阴影 | `0 2px 6px rgba(70,62,48,.10)` |
| 点 | 6px `--accent`，外圈 3px 淡苔绿 |

- 它不是按钮；不要加按压/焦点/`role=button`。
- 点不能单独表意；“当前世界”文字必须存在。

### 7.2 徽标（未来）

- 16px 高，14/20/500，苔墨或锈色底/字；必须有数字或文字。
- 不用纯色点做未读/错误；不用彩虹色。
- 底栏徽标不得改变 tab 尺寸；用绝对定位，热区不变。

### 7.3 其他标签

- 版本/加载器是文本，不是 chip；不要给每个版本号加胶囊。
- 不要用“状态 pill”堆满界面；V2 只有 chip 一个状态标签。

## 8. 状态栏

- **只存在于设计稿**（仿制 09:41/信号/电量），用于展示整体观感。
- 真实 App 必须用系统状态栏 + `WindowInsets`；纸面浅色需要**深色状态栏图标**。
- 高度 44（含安全区上边距）；文字 14/20/600，色 `#4A4D42`。
- 不要在 App 里画一条假状态栏；不要把内容顶到刘海/挖孔下。

## 9. 弹层 / 对话框（未来基线）

当前未实现。未来页面（管理菜单、删除确认、下载详情）必须遵守：

| 项 | 值 |

## 11. 组件验收清单

- [ ] 每个组件都能在 `design-tokens` 里找到全部数值。
- [ ] 每个可交互组件有默认/按压/焦点；禁用/加载/空/错按矩阵补齐或明确不适用。
- [ ] 触控热区：启动 48、图标 44、底栏 54、行 70。
- [ ] 只有灵动岛有模糊；底栏/纸卡/明信片是实色纸。
- [ ] 玻璃上的文字是墨色，对比度 ≥4.5。
- [ ] 所有可点元素有可访问名称；装饰图标 aria-hidden。
- [ ] 长文本省略不裁切；启动按钮不被挤压。
- [ ] 按压 120ms；焦点环不被裁切。
- [ ] 没有嵌套按钮/嵌套卡片。
- [ ] 空/错/载状态有文案和恢复路径。
