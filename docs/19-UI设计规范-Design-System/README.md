# FCL UI 设计规范 · V2 纸质

> **版本**：2.0.0 · **日期**：2026-11-05
> **状态**：设计规范 + 可运行 HTML 原型；**尚未实现进 FCL Android 源码**。
> **当前基准**：V2 纸质 · 竖屏 390×844。V1 深色仅作存档，不得在新界面中使用。

---

## 0. 30 秒版

- **一句话**：把界面做成一页压平的纸 —— 纸面是底，墨线是字，苔绿是唯一的印色；只有底栏上方的灵动岛是一层乳白磨砂玻璃。
- **看原型**：[`prototypes/home-paper-v2.html`](prototypes/home-paper-v2.html)（单文件，浏览器直接打开）。
- **看截图**：[`screenshots/home-paper-v2.png`](screenshots/home-paper-v2.png)（390×844 @2x）。
- **实现取数**：[`design-tokens.css`](design-tokens.css) / [`design-tokens.json`](design-tokens.json)。
- **硬规则**：见 [§5 十条硬规则](#5-十条硬规则must)；评审清单见 [`06-governance-and-checklist.md`](06-governance-and-checklist.md)。

> 这套规范服务于 **modded-fcl-ui / FCL 启动器界面**。它定义“新界面应该长什么样、怎么动、怎么实现”，不是对现有 FCL 界面的逐项修补说明。现有 FCL 是横屏 + 自造 `FCL*` 控件 + ThemeEngine；新设计是竖屏纸质 + 显式 token。两者不能混用颜色系统。

## 1. 这套规范解决什么

| 要解决的问题 | 本规范的答案 |
|---|---|
| 新页面各做各的，颜色/字号/圆角漂移 | 唯一 token 源 + 组件合同 + 评审清单 |
| 玻璃、纸、墨、苔绿被随手混用 | 材质分层：纸是结构，玻璃只给灵动岛 |
| 文字太小、对比度不够、触控太窄 | 14/16 字号底线、4.5:1、44/48dp 触控 |
| 动效套路化、掉帧、无法降级 | 只动 transform/opacity、无循环、reduced-motion |
| 接手的人不知道从哪读、哪些还没定 | 读法、决策记录、未决问题、接手清单 |

### 1.1 范围

**包含**：色彩、字体、间距、圆角、材质与高度、图标、动效、主界面布局、灵动岛、纸质底栏、明信片主视觉、世界列表、按钮/标签、可访问性、文案、实现映射、治理流程。

**暂不包含**（不要在本规范里自行发明）：

- 横屏布局（未批准；见 [`03-layout-and-responsive.md`](03-layout-and-responsive.md) §6）。
- 下载页 / 设置页 / 账户页的页面级设计。
- 灵动岛展开态、真实启动进度、失败恢复。
- 深色纸 / 夜间主题。
- 模组关系图等已有功能的视觉重做。

新页面可以复用本规范的基础与组件；页面级设计必须先补文档、再实现。

## 5. 十条硬规则（MUST）

> 这十条是“统一规范”的底线。违反任何一条，界面不得合并。

1. **只能用 token**：颜色、字号、行高、间距、圆角、时长必须取自 `design-tokens.css/json`；禁止在布局里写死 hex、字号、圆角、动画时长。
2. **只有一个 UI 强调色**：苔墨 `#4C6143`。苔绿 `#7F9470` 只做点/淡洗；淡锈/赭石只出现在插画和缩略图。禁止紫蓝渐变、霓虹、第二个按钮强调色。
3. **材质分层**：纸是结构，玻璃是交互。只有灵动岛可以用 `backdrop-filter`；纸卡、纸底栏、明信片**禁止**玻璃/模糊。
4. **禁止纯黑纯白**：纸面 `#F1EEE6 → #E2DDD1`，墨 `#2C2E28`；纯白只允许出现在玻璃高光的 `rgba(255,255,255,…)` 里，不能当画布。
5. **字号底线**：正文 16，辅助/标签 14；不得出现 14 以下。中文不做负字距。
6. **触控底线**：主启动 48×48；其他可点目标至少 44×44；底栏项 54 高；世界行 70 高。视觉可以更小，热区不能。
7. **对比度 4.5:1**：正文/辅助 ≥4.5；大字/图形/焦点 ≥3；玻璃/纸上都必须实测。
8. **动效克制**：只动 `transform` / `opacity` / 颜色；禁止 `transition: all`；禁止循环微动效；必须响应 `prefers-reduced-motion`、`prefers-reduced-transparency`、`prefers-contrast`。
9. **不做嵌套卡片、不做玻璃卡**：明信片里只有 chip 和图标按钮；世界行是单层纸卡；不要卡片套卡片、玻璃套玻璃。
10. **状态必须齐**：默认 / 按压 / 焦点 / 禁用 / 加载 / 空 / 错误。不能只做默认态；不能用颜色单独传达状态。

## 6. 未决问题（不要自行拍板）

| # | 问题 | 现状 | 影响 |
|---|---|---|---|
| O1 | **竖屏还是横屏** | 规范按竖屏；FCL 上游是 `sensorLandscape` | 决定整个主界面布局；横屏需另出布局并评审 |
| O2 | 底栏是否保留文字标签 | 当前保留 | 只留图标需要重新验证可发现性 |
| O3 | 灵动岛是否展开 | 当前不展开 | 展开态要新增动效/状态合同，不能直接用 CSS 宽高+模糊 |
| O4 | 深色纸 / 夜间主题 | 未做 | 浅纸夜间偏亮；需要独立设计，不能反相 |
| O5 | 真实数据 / 空态 / 错误态 | 未接 | 影响列表、岛、文案、重试路径 |
| O6 | 视频壁纸 | 当前静态纸面 | 视频 + 玻璃对比度不可控；如启用必须 60%+ scrim + 静态 fallback |
| O7 | 下载 / 设置页 | 未设计 | 新页面必须按 `06` 的“新页面配方”补文档 |

> 这些是产品/设计决策，不是实现细节。接手的人遇到 O1/O3/O4 时，**先问，不要猜**。

直接打开 `prototypes/home-paper-v2.html`。它是单文件，无外部图片/字体依赖；桌面端会自动套一个 390×844 手机框。

- CSS：`design-tokens.css`（与原型 `:root` 同名）。

### 9.3 重新出截图（本机）

```bash
chromium-headless --no-sandbox --hide-scrollbars \
  --force-device-scale-factor=2 --window-size=390,844 \
  --screenshot=home-paper-v2.png \
```

- 本目录的 CSS/SVG/HTML 原型为原创实现，随本仓库以 **GPLv3** 发布（与仓库一致）。

- “Minecraft / 我的世界”是 Mojang / Microsoft 的商标；本项目是非官方启动器，界面中不暗示官方授权。
