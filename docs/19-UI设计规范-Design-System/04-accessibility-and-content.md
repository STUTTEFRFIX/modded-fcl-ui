# 04 · 可访问性与文案

> 对比度、触控、焦点、读屏、降级，以及中文界面该怎么写。
> 可访问性不是“附加项”；没有通过本页的界面，不算符合规范。

---

## 1. 对比度

### 1.1 底线

| 类型 | 最低 |
|---|---:|
| 正文 / 辅助文字 | **4.5:1** |
| 大字（≥18.66px 粗 / 24px 常规） | 3:1 |
| 图形/图标/焦点环 | 3:1 |
| 禁用文字 | 不强制，但必须能看出“不可用”，且不能与背景混在一起 |

### 1.2 本系统实测

| 前景 / 背景 | 对比度 | 结论 |
|---|---:|---|
| 主文字 `#2C2E28` / 纸卡 `#F8F6EF` | **12.70:1** | ✅ |
| 主文字 / 纸面 `#F1EEE6` | **11.85:1** | ✅ |
| 主文字 / 乳白岛 `#F2EEE5` | **11.87:1** | ✅ |
| 次级 `#55584C` / 纸卡 | **6.73:1** | ✅ |
| 辅助 `#5F6256` / 纸卡 | **5.77:1** | ✅ |
| 辅助 / 纸中 `#EAE6DB` | **5.00:1** | ✅ |
| 辅助 / 纸底 `#E2DDD1` | **4.60:1** | ✅ 底线 |
| 辅助 / 底栏 `#F6F3EA` | **5.62:1** | ✅ |
| 苔墨 `#4C6143` / 纸卡 | **6.27:1** | ✅ |
| 苔墨 / 苔洗 `#E2E7D8` | **5.38:1** | ✅ 选中态 |
| 奶油 `#F8F3E7` / 苔墨 `#4C6143` | **6.12:1** | ✅ 启动图标 |
| 状态栏 `#4A4D42` / 纸顶 | **7.45:1** | ✅ |
| 虾 `--accent #7F9470` / 纸卡 | **3.05:1** | ⚠️ 只能做装饰点，不做文字 |

### 1.3 玻璃/纸张的测量方法

- 玻璃：按**有效底色**测（本系统约 `#F2EEE5`）；不能拿“白色纸面”当背景算。
- 纸纹/水印：按纹理最深处测，不能按最亮处算。
- 底栏/纸卡：按实际渐变的中段/最暗处测；本系统最低 4.60，已留余量。
- 不能只测设计稿；实现后要在真机截图取色复测（OLED/色温/亮度会影响观感）。

### 1.4 颜色独立

- 选中、错误、禁用、成功不能只靠颜色；必须同时有文字/图标/形状/位置。
- 苔绿点必须配“当前世界”文字；错误必须配“错误/失败”文字；禁用必须有禁用外观 + 说明。
- 链接色不得硬编码霓虹绿；使用苔墨或下划线。

## 2. 触控

| 目标 | 最小 |
|---|---:|
| 主启动 | **48 × 48** |
| 图标按钮 | **44 × 44** |
| 底栏 tab | **54 高 × 1/3 宽** |
| 世界行 | **70 高 × 全宽** |
| 文字按钮 | 44 高 |
| 相邻目标间距 | ≥8 |

- 视觉可以小于热区；热区不能小于。
- 热区不能重叠；不要在 row 内再放小按钮。
- 触屏点击用 `touch-action: manipulation`，去掉 300ms 延迟。
- 按压反馈在 pointer-down 出现；不要等 click。
- 长按管理必须同时有可发现的 more/菜单入口，不能只靠隐藏手势。

## 3. 焦点与键盘

### 3.1 焦点环

```css
:focus-visible{
  outline: 2px solid var(--accent-ink);
  outline-offset: 3px;
}
.launch:focus-visible{
  outline-color: var(--ink);
  outline-offset: 2px;
}
```

- 只在 `:focus-visible` 显示；鼠标点击不显示焦点环。
- 焦点环不能被 `overflow:hidden` 裁切；按钮不要在裁剪容器边缘。
- 启动按钮在苔墨底上，用墨色环，保证在乳白/苔绿上都可见。

### 3.2 顺序

视觉顺序 = DOM/焦点顺序：

1. 账户按钮
2. 明信片 more
3. “全部”
4. 世界行（从上到下）
5. 启动
6. 底栏（首页 → 下载 → 设置）

- 不要用 `tabindex>0` 打乱顺序。
- 底栏是导航，放在最后合理；不要让键盘用户先跳过内容。
- 灵动岛信息块不是按钮，不进 tab 序。
- 未来弹层：焦点陷阱 + Esc/返回关闭 + 关闭后回到触发按钮。

### 3.3 键盘操作

- 按钮：Enter/Space。
- 底栏：左右方向键可在 tab 间移动（原生/WAI-ARIA 模式）；当前原型未实现，合同要求。
- Esc：关闭弹层；不用于退出页面。

## 4. 读屏与语义

### 4.1 标签

| 元素 | 语义 |
|---|---|
| 灵动岛 section | `aria-label="当前世界快速启动"` |
| 启动 | `aria-label="启动 {世界名}：Minecraft {版本}，{加载器}"` |
| 版本/加载器 | 可读文本；图标 `aria-hidden` |
| 明信片 | `<section aria-labelledby>`；标题 h2 |
| more | `aria-label="管理 {世界名}"` |
| chip | 文本“当前世界”；点装饰 |
| 世界行 | 按钮/可点行；名称 = 世界名 + 版本 + 加载器 + 上次游玩 |
| 底栏 | `<nav aria-label="主导航">`；按钮有可见标签 |
| 选中 tab | `aria-current="page"` |
| 状态栏 | 设计稿 `aria-hidden`；真实 App 用系统 |

### 4.2 图标

- 纯装饰图标 `aria-hidden="true"` / `importantForAccessibility="no"`。
- 只有图标的按钮必须有 `aria-label` / `contentDescription`。
- 不要用 emoji 当图标；读屏会读出奇怪的名字。

### 4.3 动态状态

- 启动中/失败/空列表用 `aria-live="polite"` 的区域播报；不要用视觉 toast 代替。
- 错误信息要与具体对象关联（“红石实验室读取失败”），不要只播“出错了”。
- 删除等破坏性操作要有确认；读屏焦点移到确认按钮。

## 5. 降级

### 5.1 reduced-motion

- 关闭入场位移/缩放、按压缩放、指示胶囊位移；
- 保留 200ms 内的颜色/透明度变化；
- 不播无限 loop；loading 用静态文字或低动效指示。
- Android 读取 `Settings.Global.ANIMATOR_DURATION_SCALE` / `ValueAnimator.areAnimatorsEnabled()`。

### 5.2 reduced-transparency

- 灵动岛改为实色 `#F7F4EC`，去掉 `backdrop-filter`；
- 底栏/纸卡本来就是实色，不受影响；
- 不要因为减少透明而降低文字对比。

### 5.3 prefers-contrast: more

- 墨色加深：`--ink #1E201B`、`--ink-2 #3F4237`、`--ink-3 #4B4E42`；
- 边框加深；
- 不要用纯黑/纯白；不要用更亮的荧光色。

### 5.4 不支持模糊

- `@supports not (backdrop-filter: …)` → 实色 `#F7F4EC`；
- 不影响布局/文字；不要用一张半透明 PNG 假装模糊。

### 5.5 字体缩放

- 支持系统字号；不裁切；不缩小到 14 以下；
- 岛/底栏可增高；明信片纸签可增高；列表行可增高；
- 真机测 1.0/1.3/2.0。

## 6. 文案

### 6.1 语言

- 简体中文；按钮用动词/名词，不用营销口号。
- 不用 emoji；不用“unleash / elevate / next-gen / seamless”等空话。
- 版本号/加载器保留英文原名：`1.21.5`、`Fabric 0.16.9`、`Forge 47.2.0`、`NeoForge 21.1.0`。
- 世界名用用户自己的名字；不要替用户改名。

### 6.2 格式

| 内容 | 格式 | 例 |
|---|---|---|
| 版本 | `{major}.{minor}.{patch}` | `1.21.5` |
| 加载器 | `{Loader} {version}` | `Fabric 0.16.9` |
| 元信息 | `{版本} · {加载器} · 上次游玩 {相对时间}` | `1.21.5 · Fabric 0.16.9 · 2 天前` |
| 相对时间 | 今天 / 昨天 / N 天前 / N 周前 | `2 天前` |
| 计数 | 阿拉伯数字 + 量词 | `4 个世界` |
| 页头副标题 | `{N} 个世界 · 上次游玩 {时间}` | `4 个世界 · 上次游玩 2 天前` |

- 分隔符统一 ` · `（前后空格）；不要混用 `/`、`|`、`-`。
- 数字用 tabular-nums；时间不跳。
- 中文标点用全角；英文/数字与中文之间不强制空格，但保持一致。

### 6.3 空 / 载 / 错

| 状态 | 标题 | 说明 | 动作 |
|---|---|---|---|
| 空（无世界） | 还没有世界 | 新建一个世界，或从整合包导入。 | 主按钮“新建世界”；次按钮“导入整合包” |
| 加载 | 正在读取世界… | 首次启动可能需要几秒。 | 无；骨架/进度 |
| 错误（读取失败） | 世界读取失败 | 检查存储权限后重试。 | “重试”；“查看日志” |
| 错误（实例损坏） | 实例不完整 | 缺少版本或加载器文件，可能无法启动。 | “修复”；“打开文件夹” |
| 无选中世界 | 选择一个世界 | 从下方列表选择，或新建。 | 列表/新建 |
| 启动失败 | 启动失败 | 查看日志了解原因；可尝试更换渲染器。 | “重试”；“查看日志” |

- 空态不要只写“暂无数据”；给出下一步动作。
- 错误不要只写“出错了”；说明对象、原因、恢复路径。
- 加载态不要用整页 spinner 遮住已有内容；用骨架/局部进度。

### 6.4 破坏性操作

- 删除世界/实例：必须说明对象、后果（存档是否一起删除）、是否可恢复；用 `--error` + 二次确认。
- 备份：说明备份位置/大小；不要静默。
- 重命名：校验空名/重名；错误内联显示。
- 不要用“确定/取消”这种无对象文案；用“删除世界”“保留”。

### 6.5 假数据

- 原型里的世界名/版本/加载器是演示数据；实现时替换为真实实例。
- 不要使用假 KPI（99%、10×、∞）、假用户评价、假下载量。
- 不要把“示例”数据带进发布版；空态就显示空态。

---

## 7. 长文本与中文

- 世界名可能很长/含 emoji/特殊字符；必须省略/换行，不撑破布局。
- 元信息可能包含长加载器版本；1 行省略，保留版本在前。
- 中文标题不做负字距；不要两端对齐。
- 不要在中文里混入英文全大写标签；需要强调用字重/字号。
- 数字/英文与中文混排时保持同一行高；不要用不同字体家族。
- 测试：超长世界名、空名字、纯英文、纯数字、emoji、重名、RTL 文本（至少不崩）。

## 8. 可访问性验收清单

- [ ] 正文/辅助 ≥4.5:1；大字/图形/焦点 ≥3:1；实测记录在案。
- [ ] 苔绿点不单独表意；错误/选中/禁用有文字/图标。
- [ ] 启动 48、图标 44、底栏 54、行 70；热区不重叠。
- [ ] 焦点环可见、不被裁切；键盘顺序 = 视觉顺序。
- [ ] 所有图标按钮有可访问名称；装饰图标 aria-hidden。
- [ ] reduced-motion / reduced-transparency / contrast 三套降级生效。
- [ ] 字体缩放 1.3×/2.0× 不裁切。
- [ ] 空/载/错/启动失败有文案和恢复路径。
- [ ] 没有假数据、emoji、营销空话。
- [ ] 删除等破坏性操作有对象说明 + 二次确认。
- [ ] 真机深色/浅色系统设置下状态栏图标正确（浅纸 → 深图标）。
