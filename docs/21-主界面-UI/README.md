## 1. 这一版做了什么

不是静态稿，是**能点的界面**：三页主界面 + 灵动岛 + 两层弹层，交互和状态都写进去了。

| 区域 | 内容 |
|---|---|
| 状态栏 | 仿制（真机用系统状态栏） |
| 页头 | 页标题 + 页副标 + 账户入口 |
| 世界 | 明信片（当前世界）+ 其他世界列表 + 空态 |
| 下载 | 四段分类 + 搜索 + 结果列表 + 安装进度 |
| 设置 | 外观 / 性能 / 关于三组 |
| 灵动岛 | 版本 + 加载器 + 启动；启动时显示进度 |
| 底栏 | 世界 / 下载 / 设置（规范 D3：三项） |

## 2. 交互清单（都已实现）

| 操作 | 反馈 |
|---|---|
| 点底栏 | 页面淡入上移切换，底栏印色胶囊跟随 |
| 点灵动岛 | 弹出「选择版本」底部弹层 |
| 选版本 | 打勾、灵动岛立即更新、toast 提示 |
| 点启动 | 灵动岛进入 launching，底部 3px 进度条走完 → toast |
| 点世界卡片 / 行 | 弹出该世界的操作弹层（进入 / 设为当前 / 删除） |
| 删除 | 确认框 → 列表移除 → toast「已删除，点此撤销」→ 点 toast 恢复 |
| 设为当前 | 明信片立刻切换，页副标同步 |
| 切分类 | 先出骨架屏，420ms 后出结果（模拟网络） |
| 搜索 | 实时过滤；无结果显示空态 + 「清空搜索」 |
| 安装 | 按钮变百分比 + 行内进度条 → 「已安装」并置灰 |
| 设置 | 动效开关（带 toast）、下载线程 1–64 步进、深色纸为禁用态 |
| 键盘 | `Esc` 关闭弹层 |

状态覆盖：默认 / 按压 / 焦点环 / 禁用 / 骨架加载 / 空态 / 进度。

## 3. 设计约束

- 只用 token：纸 `#F8F2E3 / #F2EAD7 / #E8DDC4`、卡 `#FCF8EE`、墨 `#2C2E28`、苔墨 `#4C6143`、线 `rgba(122,104,72,.16)`。
- 唯一强调色苔墨；苔绿只出现在插画。
- 字号：页面标题 32、卡片标题 22、正文 16、辅助 14，无更小字号。
- 触控：行 70、灵动岛启动 44（热区 48）、底栏项 54、弹层项 56。
- 只有灵动岛用毛玻璃（`backdrop-filter`），纸卡与底栏是实色。
- 动效只动 `transform` / `opacity`；`prefers-reduced-motion` 全关。

## 5. 热区标注（指尖 44–48）

原则：**眼睛看到的可以小，手指摸到的不能小**。成人指尖 44–48dp，任何可点元素**热区高度 ≥44**，视觉可以更小。

原型内置标注层：按 H 或访问 cl-paper-v1.html?hit=1；
虚线 = 可点击热区，实线 = 视觉高度，标签 = 高×宽；左下角开关，右下角图例。

### 5.1 实测热区（标注层读数）

| 控件 | 视觉高 | 热区 | 结论 |
|---|---|---|---|
| 账户头像 / 更多 | 44 | 44 | ✅ |
| 「全部」链接 | 44 | 44 | ✅ |
| 世界行 | 70 | 70 | ✅ |
| 灵动岛 | 64 | 64 | ✅ |
| 灵动岛启动钮 | 44 | **48** | ✅ 视觉小、热区大 |
| 底栏项 | 54 | 55 | ✅ |
| 分类段（整合包/模组…） | 38 | **44** | ✅ ::before 补到 44 |
| 开关 | 28 | **44** | ✅ 已补 |
| 线程步进 | 32 | **44** | ✅ 已补 |
| 搜索框 / 安装 / 弹层项 | 44 / 44 / 56 | 同左 | ✅ |

补齐方式统一：控件加 ::before{height:44px} 垂直撑开，视觉尺寸不变。
Android 对应 TouchDelegate，或容器 minHeight=44dp + 负 padding 反补。

- 账户头像 44 已达下限，要不要提到 48？

## 6. 规范审核与修复（2026-11-14）

对原型做了逐条规范审核（Material 3 / Android 平台 + Apple HIG + 通用交互原则），按严重度修复如下。

### 6.1 已修

| 编号 | 问题 | 修法 |
|---|---|---|
| P3 | **reduced-motion 下底部弹层常显**（隐藏只靠 `translateY`，被 `transform:none` 拉回屏内） | 弹层改用 `visibility+opacity+transform` 三重控制；reduced-motion 只去位移。实测关闭态 `visibility:hidden` |
| P1 | **world 没有绑定自己的实例**：点 1.20.1·Forge 的世界却用 1.21.5·Fabric 启动 | `worlds[].profileId`；启动、明信片、行、弹层统一按世界取实例；岛屿同步显示该实例。实测点「红石实验室」→ 岛加载器 `Forge 47.2.0 · 红石实验室` |
| P2 | 删除文案与行为不一致、撤销不恢复当前世界 | 改为「从列表移除 / 不会删除存档文件」，按钮「保留 / 移除」，撤销恢复 `currentWorldId` |
| P6 | 热区数字是**编的**（`max(rect, 约定值)`），并非真实命中区 | 改为 `elementFromPoint` 四向逐像素探测；标注按 ≥48 绿 / <48 红。同步把图标按钮改到真实 48、短板用 `::before` 补到 52 |
| P7 | placeholder 3.79:1、开关 off 轨道 1.13:1 | placeholder 去透明度用 `--ink-2`（6.86:1）；开关边框改 `--ink-3`（5.88:1） |
| P8 | 4 处 13px，与「无更小字号」自相矛盾 | 统一 14/20 |
| P9 | 焦点环被 `.rows` 裁切；搜索框 `outline:0` 无焦点 | 行/弹层项改 inset 焦点；搜索加 `:focus-within` |
| P10 | 「动效」开关不生效 | 接 `body.no-motion`；补 reduced-transparency、`@supports` 毛玻璃回退、`prefers-contrast` |
| P13 | 底栏/岛/toast 未计安全区，标签落进手势区 | 三者改 `calc(... + env(safe-area-inset-bottom))` |
| P14 | `(max-height:860)` 让 390 原型在桌面被拉满 | 全屏只按宽度；宽而矮的窗口保留手机框并允许滚动 |
| P5 | 世界管理只剩长按，键盘/读屏无入口 | 每行加独立「管理」按钮（48×50），`Shift+F10` 也能打开 |
| P22 | 切 tab 回到顶部 | 每个 tab 记住自己的 `scrollTop` |

### 6.3 明确不改的

- 底栏 14px 标签（Material 是 12sp）：中文可读性优先，项目硬规则也要求 ≥14。
- 72 高的纸底栏 + 印色胶囊：品牌结构，项高 55 已 ≥48，登记为有意偏差。
- 图标视觉保持 44–48，热区再扩到 48：即「看着小、摸着大」。
