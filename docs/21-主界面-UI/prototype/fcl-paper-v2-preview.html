设计审核 · 本次改版

基于 V2 纸质规范与 fcl-paper-v1.html 的审查结果。只改 UI，不涉及 Android 实现。

保留

  • 纸质语言：纸面、墨线、苔绿唯一强调色；只有灵动岛用玻璃（液态玻璃，磨砂为降级）。
  • 主结构：明信片主视觉、世界纸卡、纸质底栏、灵动岛 64 / 40 / 48 的尺寸节奏。
  • 可访问性硬规则：正文 16 / 辅助 14 下限、4.5:1 对比度、44/48 触控、状态不只靠颜色。
  • 动效原则：页面过渡只动 transform / opacity；液态玻璃是纯 CSS 静态高光，不跑动画；响应 reduced-motion、reduced-transparency、prefers-contrast。
  • 世界与实例绑定：启动用的是世界自己的实例，不借用全局「当前实例」。

修正

  • 信息架构：底栏从 3 项改为 4 项，新增「版本」页，补齐实例、模组、资源包、光影、存档入口；账户仍在页头。
  • 灵动岛·液态玻璃：改成纯 CSS 方案——低模糊 backdrop-filter + 一张静态径向位移图（feDisplacementMap）+ 渐变描边（左上亮、右下暗）+ 顶部柔光 + 底部内阴影：背景中心保持清晰，靠近边缘向中心压缩，形成凸起玻璃的弯曲。透镜图是静态的，没有动画湍流，只作用于灵动岛这一小块。思路参考 yzrt 的纯 CSS 液态玻璃。降低透明度或关闭「液态玻璃」开关时退回普通磨砂。
  • 误触：明信片原先整卡点击直接启动，容易误触，也和文档「点卡片打开操作」不一致；现在整卡打开世界操作，启动只由灵动岛启动键负责。
  • 隐藏操作：世界行原先依赖长按才能管理；现在管理按钮常显，主操作与管理拆成两个按钮，去掉 role=button 里再套按钮的嵌套交互。
  • 下载分类：4 个等分按钮在 390 宽下会挤压；改为可横向滚动的 chip，单项最小 80×44。
  • 死控件：设置里的「深色纸」禁用开关没有解释；改为「规划中」说明入口，并注明深色纸需要独立设计。
  • 死路：账户 toast、全部世界 toast、新建世界 toast 改为可打开的弹层；新建世界在预览里可真正创建。
  • 状态：补齐加载、空、错误三种演示状态；错误态提供重试，空态提供下一步。
  • 焦点：弹层打开后聚焦、Esc 关闭、关闭后回到触发按钮；底栏支持左右方向键。
  • 动效：频繁切页从 480ms 缩短到 280ms；弹层入场保留 420ms，仍然只动 transform / opacity。
  • 字号：设置里提供标准 / 大两档，验证所有尺寸从 token 走，正文与辅助字号不低于 14。

去掉

  • 「长按才能管理」的唯一路径。
  • 禁用且无解释的深色纸开关。
  • 整卡点击 = 启动的误触行为。
  • 横向挤成一排的 4 个等分分类按钮。
  • 交互控件里再套交互控件的无障碍问题。

未做

  • 横屏布局、深色纸、灵动岛展开态、真实账户 / 下载 / 启动数据。
  • Android 实现与 APK 构建；本文件只验证 UI。
